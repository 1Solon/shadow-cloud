# Save downloads are public

Downloading a save needs no Shadow Cloud authentication: anyone with a save's link can fetch it, including saves from campaigns they don't play in. This is deliberate. A player swapped into a campaign must be able to catch up on it before they hold a seat, and other groups of players should be able to inspect an ongoing campaign for strategy or detail. Regimes inside a save stay protected by their in-game passwords, not by Shadow Cloud. Don't add an auth guard to the download route.
