# Add coherent Companion server contracts

The API will expose a compact authenticated Companion observation with an ordered Save-publication catch-up cursor, revision-bound downloads, immutable Turn-submission receipts, stable machine-readable rejection reasons, and read-only receipt lookup by operation key. The feed preserves every accepted Turn submission in server order and reports the current canonical replacement identity associated with it, allowing a paused or offline companion to catch up without treating transient administrative revisions as new turns. Existing list, detail, download, and upload behavior exposes inconsistent state, permits bytes to change under a FileVersion ID, and cannot always distinguish an absent submission from a committed upload whose response was lost. A production HTTP adapter and deterministic test adapter hide this transport contract behind the Rust engine's Shadow Cloud interface; React never composes server responses or concurrency tokens.
