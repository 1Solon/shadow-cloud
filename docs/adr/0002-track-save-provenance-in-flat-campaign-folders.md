# Track save provenance in flat Campaign folders

Each Campaign uses one flat Campaign folder containing both downloaded and locally produced save files. The Desktop companion distinguishes Received saves, Turn candidates, Ignored candidates, and already sent contents by durable content identity rather than separate inbox and outbox directories or filenames. Every Campaign folder has a readable name with a stable identity suffix and a marker containing its complete immutable Campaign ID. It is rediscovered by that marker after a move or reinstall and is never renamed automatically when Campaign metadata changes. A matching marker permits recovery; a missing, invalid, or different marker makes an existing path a collision that stops setup. Remote filename collisions preserve both files. This keeps Shadow Empire's file workflow simple, at the cost of requiring reliable provenance storage and treating ambiguous local contents as unsafe rather than guessing.
