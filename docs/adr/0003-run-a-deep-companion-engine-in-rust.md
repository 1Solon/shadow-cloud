# Run a deep companion engine in Rust

The Tauri Rust process owns one deep companion engine covering folder reconciliation, file provenance, transfer orchestration, conflicts, queues, and durable state. One coordinator serializes decisions and SQLite writes; reconciliation derives safe work and UI projections from recorded facts and user intent, while a small typed operation ledger protects one-time Send and Receive effects with immutable inputs and recoverable outcomes. Stale submissions require renewed authorization, Save conflicts have no force-send path, and only resolved engine-owned staging copies may be reclaimed automatically. Its external interface is limited to obtaining an application snapshot, issuing a typed user command, and subscribing to state changes; React renders that state but never accesses files, credentials, or Shadow Cloud directly. Keeping the engine independent of the webview lets tray operation survive window recreation and concentrates safety rules behind the same interface used by production and tests.
