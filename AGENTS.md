## Agent skills

### Issue tracker

Issues and specs live in Linear's shadow-cloud project. Before fetching,
publishing, or updating work, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles as Linear labels, separate from workflow
status. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` and `docs/adr/`. Before exploring, read `docs/agents/domain.md`.

### Web style guide

Before building or changing web UI, read `docs/style-guide.md` and match its colour, type, layout and state rules.

### Releasing

Before releasing, deploying, or answering what is live in production, read `docs/releasing.md`.

### Turborepo

Before changing Turborepo configuration or commands, read `docs/README.md` in the installed `turbo` package (resolve it from a workspace that depends on `turbo`); its docs match the installed version.
